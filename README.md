## Features

- Cinematic loading screen with progress counter
- Custom cursor with trailing ring effect
- Film grain noise & scanline overlays
- Scroll-triggered reveal animations
- Animated skill bars & stat counters
- Running timecode & audio waveform visualization
- Infinite scrolling skills marquee
- Fully responsive design
